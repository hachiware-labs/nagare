# Nagare UI プロトタイプ (Fable-5 再設計)

`index.html` をブラウザで開くと、クリック遷移できる高忠実度プロトタイプが動く。
ビルド不要・単一ファイル。右下の PROTO バーから任意の画面へジャンプできる。
URLハッシュでも直接開ける(例: `index.html#detail-review`)。

## デザイントークン

https://hachiware-labs.com/ の実装から抽出したトークンに準拠する。

- 面: コンテンツ背景 slate-50、カード面は白 + slate-200 (1px) 境界線 + 微細な影(0 1px 2px)
- テキスト: slate-950 / slate-700 / slate-500
- primary: indigo-700 (hover: indigo-800)、選択・ホバー面: indigo-50、focus ring: indigo-400 の3pxソフトリング
- 意味色: success (green-700系) / warning (amber-700系) / danger (red-700系)
- 角丸: 8px 統一。ヘッダーは白88%+ブラー
- 質感: primaryボタンは上端ハイライト付きの微グラデ+押下で沈む。行カードはホバーで1px浮く。モーダルは境界線+2層影

## ハーネスの設計方針

エージェントの動作を「信じるしかないログ」ではなく「読める監査線」にする。

1. 各工程カードに **割り当ての根拠**(なぜこのエージェントか)を1行で出す
2. **使用した知識** をチップで出し、ドメイン知識の寄与を見えるようにする
3. レビューは **ルーブリック項目単位** で判定・根拠・懸念を並べ、総合点はその集計として見せる
4. 差し戻しコメントはレビュー懸念を引用し、次の実行への指示として渡す
5. raw log・内部IDは「診断」リンクの先に隔離する
6. AI支援は2形態を必ず並置して示す: ✨生成支援(ユーザー起点・挿入して編集) / !改善提案(実績起点・受信箱・全文Diff)。提案0件でも枠を出す
