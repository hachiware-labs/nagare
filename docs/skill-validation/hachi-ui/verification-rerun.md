# hachi-ui 検証再実行記録

## 対象と目的

対象は `UI_PLAN.md` と `agent-skill-scope-1440.svg` である。成果物は、Nagare のワークスペース管理者が担当AIごとの有効Skill、適用元、グローバル継承による警告と影響を一画面で比較し、優先して修正する割当を安全に選べるようにするデスクトップ設定画面のモノクロワイヤーフレームである。

## 確認した構造

- 計画書では、管理者の判断を「有効Skillの確認」「個別設定かグローバル継承かの判別」「修正優先度の決定」「影響と復帰方法の確認」として定義している。担当AI、Skill、割当、グローバル既定、修正候補のオブジェクトと整合する。
- 画面は、左ナビゲーション、上部のグローバル継承警告、優先度付きの割当表、選択中の修正候補、下部の根拠ストリップで構成される。主領域の割当表と右側の選択詳細は、`Settings Dependency Map` と `Permission / Role Matrix` の選択理由・領域配分・視線順序に合う。
- SVGは 1440×1024 の `viewBox`、`title`、`desc`、意味のあるグループID（`sidebar`、`assignment-table`、`selected-fix-panel`、`provenance-strip` など）を持つ。外部アセットやスクリプトはなく、ラベルは編集可能な `<text>` で記述されている。

## 確認した操作と状態

- 警告付きの担当AIを優先度順に一覧し、表示条件と担当で絞り込める。選択中の「資料調査AI」では、個別の `hachi-search` とグローバルから継承した `browser` を、適用元と状態を含めて比較できる。
- 「グローバル設定を見る」「割当を修正」「詳細を開く」「変更を取り消す」の導線があり、主操作は選択中の不要な継承を当該担当AIだけ除外することとして明確である。
- `UI_PLAN.md` には、問題なし、編集不可、競合、空状態、および取消・グローバル設定確認・例外申請による回復が定義されている。SVGは現在の「グローバル継承警告あり」状態に絞り、非アクティブな例外状態を主画面へ過剰表示していない。

## 検証観点と結果

- スモークチェック: `ui_plan_check.py UI_PLAN.md` と `svg_smoke_check.py agent-skill-scope-1440.svg` はともに `OK`。
- 視覚・構造確認: 利用可能なSVGレンダラーが見当たらなかったため、SVGソースを座標、領域境界、ラベル、行高、列揃え、画面外要素の有無で確認した。1440×1024 の範囲内で、表・詳細・根拠の各領域と主要操作を確認でき、テキストの推定オーバーフローや画面外要素はスモークチェックでも報告されなかった。
- 意思決定面: 警告→優先度付き割当表→選択詳細→修正操作の視線経路が明確である。根拠は必要最小限を下部へ分離し、内部IDや実装用語を主判断面に露出していない。
- ルーブリック: 91/100。目的・意味設計・構造・操作状態・編集可能なSVG構造を満たし、80点の受入基準を上回る。モノクロはワイヤーフレーム段階として意図された表現であり、ブランド設計の不足とは扱わない。

## 適用Skillの範囲

本検証で適用したSkillは **hachi-ui のみ** である。UIの意味設計、設定依存関係と権限マトリクスのパターン適合性、SVG検証手順および構図ルーブリックに基づいて確認した。`hachi-readable-writing` は文章作成用Skillであり、本件の適用対象外で、使用していない。

## 結論

`UI_PLAN.md` と `agent-skill-scope-1440.svg` は、Skill割当の継承リスクを比較し、修正対象を根拠付きで選ぶという目的に整合している。hachi-ui のスモークチェック、構造確認、意思決定面の確認、ルーブリック評価を通過したため、SVGを変更せず検証済みとして受け入れる。
